# N-Santiago
App móvil gratuita que ayuda a estudiantes de la Universidad de Colima (Campus El Naranjo) a encontrar cuartos en renta sin amueblar en la Colonia Santiago, Manzanillo. Funciona como un intermediario que conecta directamente al alumno con el arrendador mediante un enlace a su chat personal de WhatsApp. No maneja transacciones ni cobra comisiones.
